Security

Protected where it's possible. Traceable everywhere else.

No platform can stop someone from photographing a screen. EduVault is built around that honest limit — controlling what it can, and making sure leaks are traceable when it can't.

Private storage

Original files sit in storage that only EduVault's own processing can reach — never a public URL a student could copy or forward.

Controlled viewer

Students read material inside EduVault's viewer. The original file is never sent to the browser.

Personalized watermark

Every page a student opens carries their name, ID, and organization — generated server-side, never something a student can request or alter.

Access control

Only students explicitly assigned to a batch or file, in an approved organization, can open it. Every request is checked.

Instant revocation

Disable a student or a file and access stops immediately — no waiting for a session to expire on its own.

Audit trail

Logins, uploads, assignments, and access events are recorded, so administrators can see what happened and when.

What EduVault doesn't claim: no web application can guarantee against a photo of a screen, an external camera, or a screenshot at the operating-system level. EduVault focuses on what it can actually control — private storage, authorization, and personalized traceability — rather than promising the impossible.
